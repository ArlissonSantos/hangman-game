# Jogo da Forca

Um jogo da forca simples desenvolvido com HTML, CSS (Tailwind), JavaScript e PHP.

## Sobre o Projeto

Este é um jogo da forca web onde os jogadores podem:

- Cadastrar-se e fazer login
- Jogar partidas do jogo da forca
- Configurar dificuldade e temas
- Ver ranking de pontuações

## Tecnologias Utilizadas

- **Frontend:** HTML, CSS (Tailwind), JavaScript
- **Backend:** PHP
- **Estrutura:** SPA (Single Page Application)

## Como Executar

1. Abra o arquivo `index.html` em um servidor web
2. Acesse a tela de login
3. Cadastre-se ou faça login
4. Comece a jogar!
